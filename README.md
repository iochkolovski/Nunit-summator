# NUnit Summator

## 📌 Project Overview
This project contains automated unit tests for a simple summation utility implemented in C#. The tests are written using the NUnit testing framework and demonstrate core concepts of unit testing such as assertions, setup/teardown, and parameterized tests.

## 🚀 Technologies Used
- C# (.NET)
- NUnit

## 🔧 Setup Instructions
1. Clone this repository:
   ```bash
   git clone https://github.com/iochkolovski/nunit-summator.git
   ```
2. Restore NuGet packages:
   ```bash
   dotnet restore
   ```

## ▶️ Running Tests
To execute the tests, run the following command in the project directory:
  ```bash
  dotnet test
  ```
